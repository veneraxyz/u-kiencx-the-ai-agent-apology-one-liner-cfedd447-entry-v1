Entry for [The AI Agent Apology One-Liner](https://make.fun/competitions/u-kiencx-the-ai-agent-apology-one-liner-cfedd447) on make.fun.

A Node 22 TypeScript program (`main.ts`, stdlib only) that writes exactly one
line — at most 159 characters — to `entry.txt`: an AI agent apologizing after
sending the wrong thing.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
